Boundaries: pipelines produce the data, frontend presents it, and infra runs and hosts it. pages/ groups the two map pages within Copper Sushi; they are not separate products. No src/ layers. Tests live beside the source they test, such as pipelines/cnec/test_publication.py and frontend/controls/date-time-controls.test.tsx; integration tests live with the feature they exercise.

Why this split: to change a Power Flow calculation, look in powerflow; to change daily market publication, look in cnec. Each feature keeps its pure models/calculations and a data_sources/ boundary for file, network and process access. A shared helper earns a shared home only when both features use it.

“Daily” is behavior, not a component. The CNEC job fetches and publishes data. Infrastructure provisions the scheduler, retry workflow and Lambda that run it. These are different responsibilities, shown separately below.

Power Flow data and browser rendering

Export the existing solved 29 August 2024 network as a versioned dataset. Static tables contain stable node/branch IDs, branch type, endpoint IDs and geometry. Interval tables contain explicit timestamps, signed flows, capacities, node net power, load and generation by technology needed by existing tooltips. Preserve line, link and transformer identity. Define signed flow relative to the stored endpoint order.

Use typed Python models and generated browser schemas; validate on export and browser entry. Reject dangling IDs, duplicate timestamps, invalid coordinates, non-finite values and incomplete intervals. Declare units and missing-value semantics; missing values are not zero. Reuse existing snapshot calculations rather than porting solver logic to JavaScript.

Python exports data only—no Plotly traces, figures, HTML tooltips or access tokens. React builds layers, tooltips and legends. Match existing flow directions, loading emphasis, node sizing, hover contents, initial camera and scale semantics. Retain the existing hourly sequence and Central European display time (CEST for this date); never relabel source timestamps to force a calendar date. If the source sequence conflicts with the fixed-date requirement, resolve that explicitly before cutover rather than silently dropping or shifting hours.

Publish metadata and interval files under an immutable generation, then replace its manifest. Load the selected interval first; share caching and prefetch mechanics where useful. Keep CNEC’s existing v2 contract and object paths. A failed publication leaves the last complete generation available.

Shared frontend and controls

A MapControls component composes the upper-left legend, optional upper-right reference selector, and bottom date/time controls. Its inputs include title, units, scale, date mode, interval labels, selected interval and navigation callbacks. Fixed date mode renders plain date text: no chevrons or calendar. Power Flow has no reference-country selector or reference gestures. Its time chevrons advance one hour and stop at either end.

Move CNEC publication-availability queries out of DateTimeControls into the CNEC page. Share the timeline and visual controls without fetching CNEC data from the Power Flow page. Reuse the existing shared Plot and render-state lifecycle; keep CNEC country labels, contribution overlays and selection behavior in its page. Reuse the shell, navigation, basemap loading and CSS. Keep map camera stable while time changes.

Retain /, /cnec/:day?, /embed/cnec/:day?, /opf-2024 and /embed/opf-2024. Preserve CNEC URL selection and back/forward behavior; Power Flow interval selection should also survive a reload. Embedded routes omit navigation. Show loading, missing-data and retry states; do not present a stale interval as the requested one.

Infrastructure and daily job boundaries

The job is Python code that checks source readiness, fetches constraints/prices/context, validates a complete day and publishes it. Infrastructure is Terraform that provisions its scheduler, retry workflow, producer Lambda and permissions. Renaming folders must not merge these responsibilities.

Preserve the existing 15:50 Europe/Brussels schedule, delivery date pinned to the scheduled instant, completeness checks, retries, backfill behavior and manifest-last publication. Preserve existing CNEC routes and S3 keys. Power Flow and the frontend use static S3 delivery through CloudFront; the daily producer Lambda stays; do not reintroduce the retired Dash serving Lambda.

Publish Power Flow data and frontend assets before changing routing. Keep previous frontend assets and manifests for rollback. Test both normal and embed routes against the new data format; the serving infrastructure is already static. Preserve Terraform resource addresses and authoritative state; use explicit state moves if resource addresses must change. A directory rename must not replace the bucket, distribution or scheduler.
