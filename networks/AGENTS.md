# Networks Guidelines

- **sanction-by-hand** — Solved networks here are sanctioned by the user, never by an agent. The runner writes every solve to the gitignored `candidates/`; only the user's `promote` (or say-so) copies one to `opf-<day>.nc`, and committing it is the sanction. Each committed version becomes a Git LFS object that GitHub keeps forever, so promote sparingly.
