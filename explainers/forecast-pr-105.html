Read evaluation.py · evaluate()
def evaluate(reader: InputReader, config: RunConfig, output: Path,
             restore_models: Path | None = None) -> Report:
    """Build historical inputs, forecast monthly windows, then score fixed outputs.

    Save feature rows, models, predictions and the report in output. For accepted
    reproduction, restore_models selects preserved fits instead of retraining.
    """
    features = build_features(reader, config.history_start, config.end_exclusive)
    save_features(features, output)
    predictions = forecast_months(reader, features, config, output, restore_models)
    result = score_forecasts(predictions, reader.truth, config)
    save_evaluation(result, output)
    return result.report

def read_local(directory: Path) -> tuple[Report, dict[str, pa.Table]]:
    """Verify snapshot identity, hashes and schemas before returning Arrow tables."""
    manifest = json.loads((directory / "manifest.json").read_text())
    snapshot_id = manifest["snapshot_id"]
    if manifest["schema_version"] != VERSION or set(manifest["files"]) != set(SCHEMAS):
        raise ValueError("Unsupported or incomplete snapshot manifest")
    payload = {k: v for k, v in manifest.items() if k != "snapshot_id"}
    payload = json.loads(json.dumps(payload))
    for entry in payload["files"].values():
        entry.pop("key")
    if identity(payload) != snapshot_id:
        raise ValueError("Manifest content does not match snapshot identifier")
    tables = {}
    for name, entry in manifest["files"].items():
        if entry["file"] != f"{name}.parquet" or entry["key"] != f"snapshots/{snapshot_id}/{name}.parquet" or entry["schema"] != describe(name):
            raise ValueError("Snapshot file location/schema is not canonical")
        path = directory / entry["file"]
        if digest(path) != entry["sha256"] or path.stat().st_size != entry["bytes"]:
            raise ValueError(f"Snapshot file checksum mismatch: {name}")
        tables[name] = validate(name, pq.read_table(path))
        if tables[name].num_rows != entry["rows"]:
            raise ValueError(f"Snapshot row count mismatch: {name}")
    return manifest, tables

Build features before fitting

features.py · build_features()

For each delivery day, InputReader.features() first selects eligible source versions. prices.build_price_features() constructs same-clock lags and daily summaries. dataset.assemble_rows() combines them with calendar fields, aligned weather/demand and missing flags. feature_table() validates the assembled inputs as DataFrame[Features], including native dates and UTC timestamps. Outcome values are rejected at the input boundary and excluded from the feature table; labels enter only during fitting.

Receives

InputReader and the historical start/end dates.

Returns / saves

A validated Features table. Training and prediction keep that table intact; feature_matrix() converts selected columns to NumPy for CatBoost. save_features() writes typed dates and timestamps directly to features.parquet.

Review question Do the inputs reflect what was eligible at each historical issue time?

Drill down only if needed: InputReader.features() → prices.py · select_history() → dataset.py · assemble_rows(). features.py · feature_matrix() selects only the explicit FEATURES columns; it never passes the whole row to CatBoost.

Read features.py · build_features()
def build_features(reader: InputReader, start: date, end: date) -> DataFrame[Features]:
    """Build quarter-hour rows in [start, end), with no realised target values.

    Each day uses only inputs eligible by 11:00 Berlin on the preceding day.
    The input reader selects source versions and builds typed price features;
    dataset.assemble_rows joins calendar, weather/demand and missing-value flags.
    """
    rows = []
    day = start
    while day < end:
        rows.extend(reader.features(day))
        day += timedelta(days=1)
    return feature_table(rows)

training.py · fit_month()

select_training_data() pairs earlier feature rows with eligible label versions. The prices model uses calendar and price history; weather adds forecast weather; demand adds forecast demand. Receives

Returns / saves

FittedMonth; models/YYYY-MM-DD/*.cbm, reference.json and failures.json.

Read backtest.py · forecast_months()
def forecast_months(reader: InputReader, features: DataFrame[Features], config: RunConfig,
                    output: Path, restore_models: Path | None = None) -> BacktestPredictions:
    """Fit each monthly window, then predict its days without joining scoring truth.

    Features were frozen at each day's own issue cutoff. Each successive fit
    adds eligible past labels. Save models by the first delivery date of their
    window; return fixed predictions and diagnostics for later scoring.
    """
    by_day = {key[0]: cast(DataFrame[Features], daily)
              for key, daily in features.partition_by("delivery_date", as_dict=True, maintain_order=True).items()}
    predictions: list[pl.DataFrame] = []
    folds: list[Report] = []
    failures: list[Report] = []
    fallback: Counter[str] = Counter()
    crossings: Counter[str] = Counter()
    fold = config.evaluation_start
    end = config.end_exclusive
    while fold < end:
        stop = min(_next_month(fold), end)
        print(f"Fitting fold {fold} -> {stop}", flush=True)
        fitted = fit_month(reader, features, fold, config, output / "models" / fold.isoformat(),
                           restore_models / fold.isoformat() if restore_models else None)
        folds.append({"first_delivery_day": fold.isoformat(), "end_exclusive": stop.isoformat(),
                      "fit_cutoff": cutoff(fold).isoformat(), "training_rows": fitted.training_rows,
                      "reference": fitted.reference, "fit_failures": fitted.failures})
        day = fold
        while day < stop:
            rows = by_day[day]
            forecast = predict_day(rows, fitted.models, fitted.reference, config)
            predictions.append(_prediction_table(rows, forecast, fold, config))
            if forecast.failures:
                failures.append({"day": day.isoformat(), "models": forecast.failures})
            crossings.update(forecast.crossings)
            fallback[forecast.selected_model] += len(rows)
            day += timedelta(days=1)
        fold = stop
    return BacktestPredictions(Predictions.validate(pl.concat(predictions)), folds, failures, dict(fallback), dict(crossings))

Read training.py · fit_month()
def fit_month(reader: InputReader, features: DataFrame[Features], fit_day: date,
              config: RunConfig, directory: Path,
              restore_models: Path | None = None) -> FittedMonth:
    """Fit and save a month's models using labels eligible at its first issue.

    Model failures are recorded for explicit prediction fallback. Reproduction
    loads preserved models instead of refitting them, but recalibrates the
    reference from the same eligible history.
    """
    training = select_training_data(reader, features, fit_day, config.train_start)
    reference = fit_reference(reader, training.rows, training.targets, fit_day, config)
    if restore_models is None:
        models, failures = _fit_models(training.rows, training.targets, config, directory)
    else:
        models, failures = _restore_models(restore_models, config)
        directory.mkdir(parents=True, exist_ok=True)
    (directory / "reference.json").write_text(json.dumps(reference, sort_keys=True))
    (directory / "failures.json").write_text(json.dumps(failures, sort_keys=True))
    return FittedMonth(models, reference, len(training.rows), failures)

Predict each day with that fit

prediction.py · predict_day()

The fitted models stay fixed for the month. Each day receives its own historically eligible feature rows. Quantiles are sorted; raw outputs remain available. The automatic method prefers demand, then weather, prices and finally the reference, depending on source availability and prediction success.

Receives

One day’s feature rows, fitted models, reference and settings.

Returns / saves

DayForecast: raw and ordered quantiles, failures, crossing counts, selected_model and fallback_reason.

Read prediction.py · predict_day()
def predict_day(rows: DataFrame[Features], models: Mapping[str, Predictor], reference: Reference,
                config: RunConfig) -> DayForecast:
    """Predict five ordered quantiles per quarter and select a usable method.

    Keep raw outputs and crossing counts. Choose demand → weather → prices →
    reference from source availability and execution success, never scores.
    An individual model failure receives the reference forecast.
    """
    ref = predict_reference(rows, reference)
    raw, predictions, failures, crossing = {}, {}, {}, {}
    for name, fields in config.features.items():
        try:
            if name not in models:
                raise ValueError("Model fit failed")
            q = np.asarray(models[name].predict(feature_matrix(rows, fields)))
            if q.shape != (len(rows), 5) or not np.isfinite(q).all():
                raise ValueError("Non-finite or incomplete model output")
            raw[name], predictions[name] = q, np.sort(q, axis=1)
            crossing[name] = int((np.diff(q, axis=1) < 0).any(axis=1).sum())
        except (CatBoostError, ValueError) as error:
            failures[name] = str(error)
            raw[name], predictions[name], crossing[name] = ref, ref, 0
    reasons = []
    chosen = "reference"
    for name in ("demand", "weather", "prices"):
        if rows["price_lags_unavailable"][0]:
            reasons.append(f"{name}:price_lags_unavailable")
        elif name in failures:
            reasons.append(f"{name}:prediction_failure")
        elif name in ("demand", "weather") and rows["weather_source_unavailable"][0]:
            reasons.append(f"{name}:weather_source_unavailable")
        elif name == "demand" and rows["demand_source_unavailable"][0]:
            reasons.append("demand:demand_source_unavailable")
        else:
            chosen = name
            break
    predictions.update(reference=ref, system=predictions.get(chosen, ref))
    return DayForecast(raw, predictions, failures, crossing, chosen, ";".join(reasons))

def score_forecasts(backtest: BacktestPredictions, truth: dict[datetime, float | None],
                    config: RunConfig) -> EvaluationResult:
    """Join realised prices only after prediction, then score common target rows.

    Keep rows without truth in the output and disclose their count. Report
    aggregate/monthly/demand scores and paired seven-day-block comparisons.
    Raise ValueError when no scoring truth exists.
    """
    predictions = _join_truth(backtest.rows, truth)
    scored = cast(DataFrame[ScoredPredictions], predictions.filter(pl.col("target").is_not_null()))
    if scored.is_empty():
        raise ValueError("No evaluation truth")
    names = [*config.features, "reference", "system"]
    breakdowns: dict[str, Report] = {}
    for group_name, group in (("month", pl.col("delivery_date").dt.strftime("%Y-%m")),
                              ("demand_available", pl.col("demand_available").cast(pl.String))):
        grouped = predictions.with_columns(group.alias("_group"))
        breakdowns[group_name] = {}
        for (key,), subset in grouped.partition_by("_group", as_dict=True, maintain_order=True).items():
            rows = cast(DataFrame[ScoredPredictions], subset.drop("_group"))
            available = cast(DataFrame[ScoredPredictions], rows.filter(pl.col("target").is_not_null()))
            breakdowns[group_name][key] = {
                "delivery_rows": len(rows), "missing_truth": rows["target"].null_count(),
                "forecast_coverage": 1., "metrics": _method_scores(available, names, config)}
    report = {
        "metrics": _method_scores(scored, names, config), "breakdowns": breakdowns,
        "comparison": paired_blocks(
            scored["target"].to_numpy(),
            {name: scored.select([f"{name}_q{q}" for q in config.quantiles]).to_numpy() for name in names},
            scored["delivery_date"].to_list(), config.bootstrap),
        "delivery_rows": len(predictions), "scored_rows": len(scored),
        "missing_truth": len(predictions) - len(scored), "forecast_coverage": 1.,
        "fallback_rows": backtest.fallback_rows, "prediction_failures": backtest.failures,
        "raw_crossing_rows": backtest.crossing_rows,
        "raw_crossing_fraction": {name: count / len(predictions) for name, count in backtest.crossing_rows.items()},
        "folds": backtest.folds, "timing_limits": TIMING,
        "limitations": ["Retrospective single-year evaluation; August–September were inspected in earlier diagnostics.",
                        "Historical price/weather availability assumed; demand UpdateTime semantics conditional.",
                        "Intervals are marginal per quarter; no trading-profitability or daily-readiness claim."]}
    return EvaluationResult(predictions, report)

Public first; private below.

The main entry point comes first, then public operations, then _internal_helpers. Public functions explain their inputs, outputs, time cutoffs and side effects where relevant. A small function earns its place by naming a real operation.

Leading underscores are Python’s convention for internal names; public-first ordering is this project’s reading convention. It is not a Python requirement.

Types describe the handoffs.

TrainingData, FittedMonth, DayForecast, BacktestPredictions and EvaluationResult replace unnamed stage results. Function arguments and returns are annotated; obvious local types are inferred.

RunConfig.from_dict() converts serialized settings to dates, a validated SnapshotId and frozen CatBoost/bootstrap/tolerance objects. Only to_dict() converts these values back to the saved JSON format. The monthly schedule, quantiles and feature inventories are fixed contracts, not constructor options. Dynamic Arrow rows and JSON reports remain heterogeneous mappings. PriceVersions and PriceFeatures validate price tables with Pandera; other input schemas retain their existing checks. The input path and tests are also annotated and included in the package-wide check. Historical investigation scripts have been retired.
