DE–LU · DAY-AHEAD AUCTION

Which price could we use
at 11:00?

Collect every publisher independently. Preserve what arrived, when it arrived, and when the validated edition was published. Critical Elements ⚡️ and forecasting can then reconstruct a decision from the same archive.

A researcher uses the DE–LU forecast to compare tomorrow’s quarter-hour price quantiles with the seasonal reference using information available by 11:00 Europe/Berlin on the preceding day. That is the input deadline. The time a researcher can retrieve the forecast is a separate observation. Forecast design principles · Baseline decision.

From publisher to decision

  1. Lambda polls each publisher. Fetch ENTSO-E, Electricity Maps, SMARD and JAO independently. Success from one never suppresses another. Tune schedules to publication windows, the consumer deadline and each publisher’s rate limits. Isolate failures and cooldowns by publisher.
  2. S3 preserves evidence. Give each poll an identity. Record publisher, dataset, request scope, outcome and completion time. Save the response and receipt time even for partial or malformed data. A timeout has an attempt record. Keep licensed payloads private and credentials out of diagnostics. Each attempt has one immutable object.
  3. Pandera validates editions for Parquet. Store published prices and signed border spreads in separate typed tables. Key versions by publisher, auction, zone or border, delivery interval and edition. Preserve units, upstream attribution and links to receipts. Publish one immutable Parquet object per delivery day and attempt, including valid zero-row editions.
  4. A shared reader selects by cutoff. Return every validated edition received by the cutoff whose S3 publication second has elapsed. Query failure diagnostics separately under the same publication rule. The resolver applies the consumer’s pinned source policy. For eligible direct prices prefer ENTSO-E, with SMARD and Electricity Maps as alternates. Require matching auction, zone, interval and unit. Surface conflicting values with both receipts. Record the selection policy version and chosen evidence in the decision manifest.
What if the writer stops halfway?

A raw response alone establishes receipt. The process might still be validating it or might have stopped. Publish validated rows with one conditional S3 PUT. If the acknowledgement is lost, retry the same attempt. Compare with the stored edition on collision. Matching evidence preserves the first object and its publication time. Conflicting evidence fails. S3 conditional writes

Which component owns each clock?

Use timezone-aware UTC columns. A weather forecast records its cycle and valid time. An auction price records its delivery interval. Preserve publisher update or publication time only with its documented meaning. Collectors witness receipt. S3 records when it published the validated edition. Reprocessing an old response today cannot backdate publication. An issued forecast separately records issue time, first observed customer availability, and the pinned inputs, model and code.

What can callers accept?

A published price points to its publisher and receipt. A derived price points to an eligible absolute price in another zone and every signed JAO spread connecting it to the target, all for the same quarter. If no anchor exists, return the missing interval and attempted sources. Reject inconsistent paths. Derivation time cannot establish earlier input availability.

Critical Elements ⚡️ can require a complete regional table and accept derived quarters. The free-source forecast baseline excludes licensed Electricity Maps inputs, including derived prices anchored to them. A later forecast policy can admit them explicitly. Forecast issuance can accept a derived input when its policy allows it and all evidence was usable by the deadline. Evaluation pins its outcome snapshot. Source audits can inspect each publisher separately.

Build and verify in slices

  1. Prove the clocks. Run at any hour. Use a controlled clock and two synthetic revisions to replay the timeline above, including a failed publisher attempt, offline through the normal reader. Separately, invoke the AWS collection path for one completed DE–LU delivery window. Poll ENTSO-E and Electricity Maps independently, retain their actual receipt and archive publication times, then replay just before and after usability with publisher access disabled. An afternoon poll proves afternoon availability. A future morning poll can establish performance against the live 11:00 deadline.
  2. Prove durable identity. Stop the writer after its first object and verify the reader sees no new edition. Publish A after cutoff and lose the acknowledgement. Retry with the same validated rows and verify the publication time stays fixed. Publish B at noon. The archive must return neither edition at 11:00, only A at 11:05, and both after noon. Query late failure diagnostics at each cutoff as well.
  3. Prove recovery. Replay November 20, 2026 as the JAO acceptance test. Recover the 384 missing zone-quarters across Croatia, Hungary, Romania and Slovakia. Match all 96 Slovak prices to the published settlement results and trace each to its anchor and spreads. Critical Elements ⚡️ incident replay.

    Manual smoke test for November 21 delivery. Compare the retained November 24 SMARD and Electricity Maps responses for DE–LU. Expect zero of 96 quarters in SMARD and all 96 directly published by Electricity Maps. Inspect the publisher and receipt time for each response. This checks retrospective coverage only.

    Use synthetic inputs in the automated tests for direct alternate selection, missing anchors, conflicting prices and receipts arriving after cutoff. Keep the November 21 payloads out of the unit suite. November 21 source comparison.

  4. Switch consumers. Run the same archived day through Critical Elements ⚡️ and forecast issuance. Trace each selected price to its evidence. For one expected forecast edition, read the output through the researcher’s normal interface and record its first observed availability, issue time, pinned model and input manifest. When required data misses cutoff and no eligible substitute exists, record a missed edition. Test replay and issuance with identical eligible inputs and feature rules. Reproduce the frozen evaluation with its original snapshot.

Start with schemas and delivery-day object prefixes as the inventory. Add a queryable catalog when finding publisher coverage or editions becomes a measured problem. A database, feature store and changes to model fitting are outside the first slice.

Existing foundations

The merged forecast pipeline already uses typed input versions and frozen S3 snapshots. The collection cadence, shared resolver and consumer integrations above are proposed work. The earlier prototype supplies a tested Electricity Maps reader, comparison cases, and evidence-preservation and naming rules to recover selectively.
