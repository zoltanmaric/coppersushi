Implementation working memory

Spec: Germany–Luxembourg price forecast

Implementation working memory, 2026-10-09. Authoritative scope: forecast design. Implementation home: forecasts/, independent of the map/power-flow application.

Problem

Build one useful public-fundamentals model for next-day quarter-hour prices, issued by 11:00 German local time, with five uncertainty quantiles and a reproducible historical evaluation.

Local baseline

Run the registered price-history comparison. Retain every delivery quarter. Verify the frozen snapshot, stop on missing required prices, and report both the model and the seasonal reference on the same dates. A measured loss is a valid result.

Restore the recorded code, locked environment, snapshot and saved models. Reproduce the predictions and scores. Check one day through the daily issue command against the same historical run. Live issuance requires receipt before the issue deadline.

Later work

Weather, demand, alternative date ranges and later cutoffs require separate research decisions. Scheduled cloud execution and shared tracking can follow the local baseline. See the infrastructure design.
